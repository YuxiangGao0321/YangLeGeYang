# 羊了个羊视觉参考与实施边界

研究日期：2026-10-25。改造目标是经典叠牌三消小游戏的视觉语言与操作手感。

## 参考依据

1. [简游科技《羊了个羊》官方介绍](https://easygame2021.com/index.php?a=index&c=Lists&m=home&tid=4)直接链接官方美术素材库，并以微信小程序作为入口。
2. [官方美术素材库：方块](https://ip.easygame2021.com/block?id=2)的“默认主题”提供牌面和16种农场图标。研究中直接查看了页面与原始透明图片。页面还收录多种主题；默认主题不是宣称2026年新发布的主题。
3. [Apple App Store《羊了个羊：星球》](https://apps.apple.com/cn/app/id1644374326)展示的当前版本为1.27.5，日期为2月10日，下一条历史记录为2025年11月3日，因此当前条目属于2026年。更新说明是活动和皮肤更新，未描述核心叠牌界面重做。《星球》的活动、卡牌收集页面不能代替经典小游戏玩法界面作为本次目标。
4. [2026年8月18日玩家通关视频页面](https://www.douyin.com/video/7675041637252389858)可核实近期有人继续发布玩法记录，但本次浏览器打开时跳转至推荐流，未成功观察该视频内容。该页面不作为动画细节证据。
5. [近期平台演示页](https://www.4k99.com/detail/5072)中的公开视频路径包含20260817。直接播放检查后确认是一段约9秒的营销混剪，包含经典叠牌画面，也混有其他片段，不能据此确认最新客户端版本或逐帧测量完整点击/三消过程。
6. [经典玩法截图及攻略](https://game.3loumao.org/842150831)用于核对绿色托盘、蓝色道具键、灰暗遮挡牌的布局。该截图属于2023年，作为经典核心视觉的历史参照，不标记为2026年截图。

下载站页面的“2026更新时间”不能单独证明游戏美术在2026年改版。没有证据支持将本次改造称为“2026最新官方版本的逐帧复刻”。

## 可直接观察的视觉特征

- 浅草绿色背景；装饰草线条稀疏，优先突出叠牌。
- 方牌正面为浅奶油黄绿色，圆角较小，深橄榄色描边，底部有明显绿色厚边，表现轻量的立体厚度。
- 图标采用明亮平涂、粗轮廓、圆角转折，少量高光和内部线条；没有复杂材质、柔光和大面积渐变。
- 默认图标的官方透明画布为120×135，牌面与图标分层。项目新图标使用64×64矢量画布，牌面由界面单独绘制。
- 16种题材依序为草、胡萝卜、玉米、木桩、叉子、白菜、羊毛团、刷子、剪刀、奶瓶、水桶、手套、铃铛、篝火、毛线球、干草捆。

经典玩法的绿色托盘、底部三个蓝色道具按钮以及中央层叠牌区是布局目标。颜色值和间距按浏览器渲染效果调校，属于项目实现参数，不是官方设计规范。

## 点击与消除动画的证据范围

本研究能确认静态图标与牌面外观，未独立获得可逐帧核实的2026官方动画录像。实现中的按压缩放、牌面飞入托盘、落位回弹、同类牌靠拢、三张牌缩放淡出与少量碎屑是对目标手感的工程重建。持续时间、缓动曲线和粒子数量均为实现调校值，不能标注为官方数据。若后续获得用户实机录像，可继续对照调整。

## 本次实现和验收

- 原创16个默认题材SVG，并为高难度和自定义扩展苹果、蘑菇、三叶草、鸡蛋、向日葵，共21种。
- 按压和飞入235ms，落位回弹95ms，匹配弹缩/闪亮/淡出255ms，余牌位置过渡180ms。缓动、星点和声音均为独立重建；不是官方逐帧参数。
- 连续点击进入顺序队列；道具操作期间阻止新的牌操作。重试和离页取消旧动画，后台页面动画回调暂停时有超时兜底。
- 撤回恢复实际来源；移出前三张进入可再次点击的暂存区；第七槽刚好成组时先完成匹配，再判定输赢。
- 手机390×844浏览器实测了同类排序、三消、快速连点、备用堆撤回、暂存牌回收、满槽和移出救回、六张牌完整通关、动画中重新开局。另检查320px窄屏和桌面宽屏无横向溢出。截图位于`doc/previews/`。
- `npm test`的10个核心回归测试通过，`npm run build`通过。

## 根据用户实机截图校准

本次以用户提供的两张 JPG 为直接视觉依据。第一张为正常关的密集叠牌，第二张为三种图案的简单关。

- 两张截图的空白背景像素分别为 `#c3fe8a` 和 `#bbf587`。界面统一采用第二张较柔和的 `#bbf587`；牌面改为浅黄绿色 `#f5fac5`、深橄榄描边和绿色厚底。
- 经典牌区宽度为屏宽的 84%，横向容纳七张牌；牌面下沿单独增加厚度。去掉牌区上方大标题、进度条和托盘说明文字，把额外操作收进齿轮菜单。
- 简单关使用 18 张牌，每种图案六张，开局七张可选；摆法为上方两组双列叠牌、下方三列叠牌。正常关为 16 种图案、144 张牌，中央交错布局配下方两个竖向备用堆。
- 原有 SVG 图片在实测浏览器中曾显示为空白，现改为将本地 SVG 作为源码打包并内嵌，牌面不再依赖单独的图标图片请求。图标仍是项目矢量重绘。
- 托盘与三个道具键按屏宽缩放并靠近屏幕底部；按钮图标、白字描边和黑色加号位于同一蓝色按钮内。窄屏出现暂存牌时增加页面可用高度，避免暂存区遮挡备用堆。

验收：12 项核心测试全部通过，生产构建通过。在 390×844 浏览器中实际完成简单关 18 次点击通关，以及正常关三消、撤回、移出暂存；检查 320×568 和 1280×900 的牌堆、托盘与道具位置。预览截图为 `doc/previews/easy.jpg` 和 `doc/previews/game.jpg`。
